# Traffic Sign Recognition

A web application for detecting traffic signs using AI.

## Features

- Upload traffic sign images for detection
- Camera capture for real-time detection
- Simple explanations for each traffic sign
- Multi-page web interface

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
streamlit run multi_page_app.py
```

## Model

- Architecture: ResNet34
- Accuracy: 74.07%
- Dataset: Bangalore traffic signs

## Supported Signs

1. No Entry
2. No Parking
3. Pedestrian Crossing
4. Speed Limit
5. Stop Sign
